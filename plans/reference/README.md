# plans/reference/

Supporting material for the plans: findings, baselines and comparisons that outgrew an inline
section. A reference doc opens with a header saying what it covers and which plan uses it, so a
session can skip it unless it is working in that area.

- [verified-on-this-machine.md](verified-on-this-machine.md): toolchain and library behaviour
  established by running it, not by reading docs. Read before touching packages or the harness.
- [time-and-scope.md](time-and-scope.md): where the build hours went and how far the result is from
  the brief. Read before adding a phase or a design decision.
- [smoke-test-findings.md](smoke-test-findings.md): what each manual pass raised and where every
  item was settled. Read before reopening a question a pass already answered.
